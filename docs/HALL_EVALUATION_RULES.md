# L東京喰種 ED中カード・設定示唆指数の評価ルール（過去のWorkでの評価を保存）

更新: 2026-10-12
状態: 将来のEDモード開発の参考。**推定モデルは暫定であり、メーカー公表の出現確率とは区別する。**

## 評価する対象
- ED中に表示されるカードの**色×キャラクター×枚数**を記録し、カード示唆を「高設定示唆 強/弱」「奇数示唆 強/弱」「偶数示唆 強/弱」「特定設定以上・設定6等の確定級」に分類する。
- 出現カードは一枚ずつ記録し、見逃しの有無も区別する。獲得枚数約2,500枚などのED消化規模ではなく**実際の観測カード枚数**を標本数とする。
- 同じ色でもキャラが異なると示唆内容・強さが違うため、色だけで判定しない。

## 過去のWorkから確認できた分類例
- 高設定示唆・強：赤鯱、赤鈴屋什造、赤亜門、赤篠原幸紀など。
- 高設定示唆・弱：赤金木、赤トーカなど。
- 奇数示唆・強：白ウタ。
- 偶数示唆・強：青まど。
- 奇数示唆・弱、偶数示唆・弱はそれぞれ別集計する。
- 確定級示唆を最優先し、過去の整理では金・神代利世＝設定4以上、金・隻眼の梟＝設定5以上、虹・有馬＝設定6としていた。**実装時は最新の信頼できる解析情報と画像対応を再確認すること。**

## 過去の評価実例（2026-10-12のWork）
観測23枚、見逃しなしという前提で：
- 高設定示唆・強：3枚（赤鯱/赤什造/赤亜門）、13.0%
- 高設定示唆・弱：2枚（赤金木/赤トーカ）
- 奇数示唆・強：1枚（白ウタ）
- 偶数示唆・強：1枚（青まど）
- 奇数示唆・弱：8枚
- 偶数示唆・弱：8枚

評価方針：**強い高設定示唆3/23を重視**し、強弱と偶奇傾向を分けて評価する。確定演出がなければ断定しない。

過去の試算で使用した参考モデル：
- 事前確率：設定1～6同率
- 個々のカードが独立抽選、見逃しなしの仮定
- 高設定示唆・強の推定出現率（設定1/4/6）：0.5% / 3.5% / 6.0%（**非公式の仮置き値**）
- この仮定の下で、設定4以上：約87%、最頻値の設定6：約44%と試算。

**上記の87%・44%は客観的に検証された確率ではなく、仮定に強く依存する参考計算。アプリの確定的な出力に転用しない。**

## 将来の指数設計に必要な考え方
1. まず色・キャラ・示唆区分・枚数・見逃しの有無を構造化して保存。
2. 「確定示唆 > 強示唆 > 弱示唆」の優先順位。確定と推定を別表示。
3. 偶奇示唆と高設定示唆を独立して集計し、相互に矛盾するカードがあっても隠さない。
4. 高設定示唆・強の観測比率を示し、カード枚数の少なさによる不確実性を説明。
5. 発生率が未公開なら『設定示唆指数』は**確率ではない参考スコア**と明記する。
6. 将来ベイズ推定を行うなら、設定別のカード出現条件付き確率と事前分布を明示し、仮定やモデルの感度分析を実施する。
7. 公開解析データにない数値をメーカー公表値と表示しない。
8. EDカードとCZ・AT実測、ホール比較の台データは別根拠として保ち、統合評価では二重計上しない。
