# L東京喰種 ホール比較・台評価ルール（記録版）

更新: 2026-10-12 / 出典: ユーザーとの「東京グールホール比較」Workで合意した評価方針の要約。
状態: 評価基準の記録・将来実装の参照資料。自動評価エンジンへの組み込みは未実施。

## 基本方針
- 1日の出玉・差枚・最大持ち玉の一撃だけで高設定と判定しない。
- **稼働量（累計スタート）・RB表示頻度・複数日で同一台番号が強いか**を主に見る。
- 最近の比較では**3日分の台データ**を並べ、同一台番号の経日変化を見る。
- RB表示はサイトの表示値であり、そのまま機種本来のCZ初当たり件数と断定しない。
- 比較用に **累計スタート ÷ RB表示回数** を計算しても、必ず「RB表示ベースの参考値」と表示する。設定別CZ確率に直接当てはめない。
- 「上げ」「据え置き」「横スライド」「並び投入」は、一覧データだけでは未確認の仮説として扱い、断定しない。
- サンプル数が少ない日の極端に良いRB参考値や一撃出玉は強い設定根拠として扱わない。
- 前日強かった台は翌日の設定保証ではない。候補順位は相対評価と明記。

## 3日間の比較の実例（Workより）
- 優先候補: **11番・44番**。
- 次点の同列候補: **15番・66番**。
- 15番の「累計スタート÷RB表示」の推移（表示ベースの参考値）:
  **263.9 → 242.3 → 201.7**。
- この推移はRB表示頻度の改善傾向の観測であり、設定上げや翌日の据え置きを証明しない。

## 過去の長期比較で使った補助基準（別期間の参考）
- 22台・7日間比較では、**累計3,000G以上**かつ **RB/CZ代理値が概ね1/235以内** を暫定的な強めの候補フィルターとして使用した。
- ただしRBとCZの同一性が未検証のため、この1/235は公式CZ設定差を直接判定する閾値ではない。期間・サイト表示定義に依存する暫定ルール。
- 複数日にわたり強い値を示す同一番号を重視（例: 2010番、2003番）。横移動規則は確認できていない。
- 並び/周辺台の挙動は補助材料にとどめ、単日で投入法則を断定しない。

## 将来の設計要件
1. 入力データには店舗・日付・台番号・累計スタート・RB表示回数・情報源・表示定義を残す。
2. 複数日の比較結果では、稼働量と日ごとのRB参考値、同じ台番号の反復、隣接台の状況を分けて提示。
3. CZ実測、RB表示、液晶G、実G、AT獲得枚数は混同しない。
4. 欠損/低サンプル/台データ表示仕様不明を明示し、確度を過大評価しない。
5. 評価ロジックは仕様書・テストを作ってから実装。バックテストで妥当性を検証。
6. 対象日の実戦判断を示す場合も、投資上限（これまでの希望:2万円）と撤退条件を別に扱い、設定保証・勝利保証を行わない。

## 注意
本ファイルは過去のWorkの判断を将来参照するために記録したもの。個別台の優先順位はその時点の対象店舗と期間に限る。新しい日付の台を恒常的に推奨する内容ではない。
